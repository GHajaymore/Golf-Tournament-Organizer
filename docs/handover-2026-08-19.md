## The decision that blocks the onboarding work

**Which kind set is authoritative?**

- `Organization.kind` in `prisma/schema.prisma` documents itself as
  `personal | club`.
- `OrgKind` in `src/lib/domain/org-profile.ts` is
  `club | course | community | personal`.

Nothing is broken today because `orgProfile()` tolerates an unknown string.
But the signup question writes a kind, the checklist reads it to decide which
steps exist, and the landing page branches on it — so building any of those
before this is settled means building them twice. **This is Ajay's call.**

## The pattern to bring to the simplification pass

Both screens Ajay called confusing were confusing for the same reason, and it
was not clutter:

- Rounds & formats — two unrelated questions under one heading ("Match points
  & tiebreakers"), so the configurable Toughest N could not be found.
- The settings — a control that CREATED a round invisibly the moment it was
  touched.

Expect to SEPARATE what got conflated more often than you remove anything.
"Simplify" here means making one thing mean one thing.

## Traps, learned the hard way

- **Read a file before writing it.** `SetupChecklist` already existed for
  per-tournament setup; it was overwritten with `Write` and only the typecheck
  caught it. The org-level one is `OrgSetupChecklist` for that reason.
- **Windows/CRLF:** `perl -0pi -e` multiline patterns fail, and node scripts
  with template literals repeatedly mangled escapes (`\d` became `d`, silently
  breaking a parser). **Use the Edit tool for structural edits.**
- **Scripts cannot import the services** without the shim — they open with
  `import "server-only"`, which throws outside Next:

      npx tsx --require ./scripts/server-shim.cjs scripts/your-script.ts

- **Hiding a section is not the same as not creating something.** The first
  attempt at "don't default the round" hid the whole block, which swapped a
  silent creation for a silent omission. A render test caught it, because that
  branch deliberately says "No round after this yet".
- **A summary is not evidence.** An earlier summary claimed D1–D9 were closed;
  re-reading the source found D5 and D6 still open.
